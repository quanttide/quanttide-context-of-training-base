敌军 AI 决策记录模块 · 任务书
1. 模块定位
敌军 AI 的每一次决策记入一份阵中日记——决策发生时的完整推理现场，当场存档，事后不得增删涂改。它是后续一切 AI 反馈工具的唯一原始档案：实验卡的比对对象、信念轨迹图的数据源、回归测试的比对面、LLM 换装的对照基准。先建采集，其他工具都是它之上的视图。
2. 前置依赖
• 敌军 AI 决策入口存在（桩版随机决策即可，不要求规则版）；
• 信念状态结构已定稿（阶段 1 的认知 schema）；
• 无需等待：不依赖仪表盘、不依赖 JSON Schema 工具链、不依赖真引擎。
插入时点：阶段 3 第 1 天，先于 AI 逻辑本身。
3. 档案格式
一个决策一条记录，存于 records/decisions.jsonl，逐条追加，只增不改——与引擎事件流同一纪律：
{“turn”: 47,
 “unit”: “enemy_div_3”,
 “weights_hash”: “a3f2c1”,
 “belief_snapshot”: {
   “target”: “cpla_1corps”,
   “est_position”: [116.42, 34.51],
   “est_strength”: 0.65,
   “confidence”: 0.41,
   “based_on”: [“intel_0213”, “intel_0219”]
 },
 “candidates”: [
   {“action”: “advance”,  “score”: 0.72},
   {“action”: “hold”,     “score”: 0.55},
   {“action”: “withdraw”, “score”: 0.31}
 ],
 “chosen”: “advance”}
字段清单：
字段	必填	说明
turn	✓	决策发生的回合号
unit	✓	决策单位 ID（与引擎单位 ID 体系一致）
weights_hash	✓	决策当时生效的性格/权重参数指纹（哈希即可），相当于该次决策所用“作战命令所依据之基准版本“
belief_snapshot	✓	决策时读到的信念状态全量快照，含 based_on 依据情报条目编号
candidates	✓	候选行动全集 + 每个候选的权重评分
chosen	✓	最终定下的决心，必须出现在 candidates 中
4. 三条实现铁律
1. 先记录，后定案——记录在打分函数内部写：快照与候选评分在 chosen 定下之前落档，如同参谋记录必须先于指挥官决心归档。严禁决断完成后回填“理由”——那是事后编写的战斗详报，会反过来误导日后研判；
2. 快照是真实输入——belief_snapshot 必须是决策函数实际读到的对象，拷贝自同一来源。严禁为求体面补入引擎真相的任何字段（这也是对称性断言的永久证据：档案里永远不该出现 truth）；
3. 桩版也记——从随机决策桩开始就接入本模块，AI 可解释性从第零天是架构属性，不是阶段功能。
5. 验收断言
• 一回合 N 个决策单位 = 档案中恰好 N 条记录，无遗漏无重复；
• 每条过最小 schema 校验（必填字段齐全、chosen ∈ candidates）；
• 同种子两次运行，档案逐条比对为空（确定性，进 CI）；
• 改任何性格参数 → weights_hash 变化 → 重跑金种子档案比对非空，且每条变化可归因到该参数；
• 抽查任意一条：根据 belief_snapshot + candidates 的评分能人肉重推出 chosen（可解释性抽查，如参谋复核下属决心）。
6. 使用方式（第一版）
不建界面。grep / jq 直接查档：
jq ’select(.unit==”enemy_div_3“ and .turn==47)‘ records/decisions.jsonl
grep ”weights_hash.*a3f2c1“ records/decisions.jsonl   # 某参数版本的全部决策
够用半年再决定要不要可视化。唯一例外：信念轨迹图可提前做——把每条 belief_snapshot 按 turn 连线、与 truth 叠加，两线间距是迷雾健康度的唯一图形化表达，文本扫不出形状。
7. 明确不做
• 不做仪表盘、不做 UI；
• 不改 CLI 现有命令（可加 hj decisions 查询命令，不改已有命令）；
• 不设“可读的理由”字段——理由就是快照+评分本身，自然语言解释留给未来 LLM 层。
8. 交付物与工作量
交付物： 决策记录写入器（嵌入 AI 决策入口）、schema 校验、确定性比对断言（进 CI）。
工作量估计：核心约 100 行代码 + 半天断言——全项目杠杆率最高的一百行。
盲区声明： 本模块回答“AI 为什么这么做”，永远回答不了“这个行为好不好玩”。后者由 L2 协议的“皱眉时刻”清单补足：真人记录不对劲的回合号，事后查档细看那一刻它信了什么、打了什么分——皱眉是前线观察哨，档案是司令部案卷，缺一不可。
